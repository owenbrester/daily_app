A helpful project to help keep me accountable each day on my goals.

Personal project app that tracks screentime, if I went to the gym, if I studied, and how long I worked out and studied.
Uses that data to make a ranking system of how I did that day; for example if I spend little time on my phone, have a good workout, and study for a good amount that day then I will get a high rank.
There is also a "streak" counter that keeps compounding points for when I go to the gym consistently, while adding rest days to continue the streak and take breaks.
